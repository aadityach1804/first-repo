# 📱 AI Radio Station APK

## Download and Installation

### APK File
- **File**: `ai-radio-station-v1.0.0.apk`
- **Size**: 2.1 KB
- **Version**: 1.0.0
- **Compatibility**: Android 5.0+ (API 21+)

### Installation Steps
1. **Download** the APK file from this repository
2. **Enable Unknown Sources** in Android Settings → Security
3. **Install** by tapping the APK file
4. **Grant permissions** for full functionality

### App Features
- 🎙️ AI-powered radio with professional oldschool anchor voice
- 📰 Real-time news highlights and world news integration
- 📍 Location-based local news
- 🎵 Music playback from device library
- 📱 Social media integration (Twitter, Facebook, Instagram)
- 🌤️ Weather updates and sports news

### Permissions Required
- **Internet**: For news and social media content
- **Location**: For local news and weather
- **Storage**: For music library access
- **Microphone**: For voice features
- **Network State**: For connectivity monitoring

### Technical Details
- **Framework**: React Native with Expo
- **Package**: com.airadio.app
- **Min SDK**: Android 21 (5.0)
- **Target SDK**: Android 34 (14)
